This SQL code creates a simple School Management System database.

CREATE DATABASE – creates the school database.
USE – selects the database to work with.
CREATE TABLE – creates tables for students, teachers, and courses.
INT – stores whole numbers.
VARCHAR – stores text.
PRIMARY KEY – uniquely identifies each record.
AUTO_INCREMENT – automatically increases the ID number.
NOT NULL – requires a value to be entered.
FOREIGN KEY – connects the courses table to the teachers table.
INSERT INTO – adds student, teacher, and course records.
SELECT * – displays all records from a table.
